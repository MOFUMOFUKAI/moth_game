# 素材調整の案内

今回、素材の画像・音声を加工していない。現在のGIF・MP3でゲームを確認できる。
その後、BB_R（赤い大型敵）はユーザー作成PNGアトラスへ試験切替済み。
元のGIFは `source-assets/alternates/enm_big_R.gif` に保管。ほかの敵・演出は従来方式。
未使用のWebP候補12個と旧タイトルPNGは `source-assets/alternates/` に保管。
ファイル名の大文字小文字も保持している。

## 優先度1：BGM

対象：`assets/audio/bgm/` の6曲、合計約19.68MB（十進MB）。
全体の容量削減では最も効果が大きい。
原音を手元に保存し、まず1曲だけ圧縮した候補を作り、ヘッドホンとスマホで聴き比べる。
音割れ、音のこもり、開始位置、ループのつながり、曲の長さを確認する。
候補はMP3で、既存名を維持できる。同じ名前ならコードの参照変更は不要。
曲ごとの音量差も確認する。音質を優先し、無理に一律の容量へ合わせない。

## 優先度2：敵・パリィ・爆発アニメーション

対象：`source-assets/alternates/` にある12個のWebP候補。
対応するGIFの合計約3.02MBに対し、WebPは約0.835MB（約72％減）。
現在はGIFを使用中。候補を見比べて、動きの速さ、ループ、透過、色、最初のフレームを確認する。
BB_RについてはWebPではなく、確認済みのアトラスを採用している。
敵を1種類ずつ、次にパリィと爆発の順で承認すると差を確認しやすい。
特にiPhone/Safariで表示と再生を確認してから、コード側をWebP参照へ変更する。
GIFを先に削除しない。承認後の配置と参照更新はこちらで行う。
素材を差し替えた際は、変更が意図したものと確認してから `docs/assets-manifest.json` とテストも更新する。

## 後回しにできるもの

タイトル・操作ボタン・背景は容量が比較的小さいため、当面は現状のままでよい。
`chr_moth.gif` は既存WebP候補がない。変換する場合は羽ばたき速度と透過を確認する。
まず現在の修正版を試し、その後にBGM1曲と敵1種類の候補から進める。
