元GIFの同じ絵が続く区間をまとめ、通常パリィは各コマ120,120,80,120,80,120,80,120,40ms、
爆発は80,80,80,40,80,80,40,80,80,40,80,40msとして再生。
1周はそれぞれ880ms、800ms。従来の表示寿命350ms/400msを維持するため、
通常の発動ではループの途中で表示を終了する（全コマを表示時間内へ圧縮する変更はしない）。

表示位置・効果音・得点/EXPポップアップ・パリィ判定と無敵時間は維持。
爆発の中心合わせと前後関係（z-index 10）も維持する。
ジャストパリィ成功時は通常パリィの表示・管理リスト・削除タイマーを即時解除して切り替える。
共通の演出管理を使用し、ポーズ中は再生と寿命を停止。
演出終了・ゲーム終了・再プレイ時は参照を解放する。
爆発を表示しないアイテム報酬の処理は維持。

旧GIFは source-assets/alternates/eff_parry.gif と eff_bomb_L.gif に移動して保管。
